VARIANS-SYNCHRO {version} — VERSION PRÊTE À L'EMPLOI

Cette archive contient Varians-Synchro et tout ce dont il a besoin (Python,
Qt) : il n'y a rien d'autre à installer.


INSTALLER ET LANCER
-------------------
Windows (10 ou 11, 64 bits)
  1. Décompressez toute l'archive (clic droit → « Extraire tout… »), par
     exemple dans Documents. Ne lancez pas Varians-Synchro depuis
     l'intérieur du zip.
  2. Double-cliquez sur Varians-Synchro.exe, dans le dossier
     Varians-Synchro-{version}.
  3. Premier lancement : Varians-Synchro n'étant pas signé, Windows peut
     afficher « Windows a protégé votre ordinateur ». Cliquez sur
     « Informations complémentaires », puis sur « Exécuter quand même ». Un
     antivirus peut aussi analyser le programme avant de le laisser démarrer.
  Pour un raccourci sur le bureau : clic droit sur Varians-Synchro.exe →
  « Envoyer vers » → « Bureau (créer un raccourci) » (sous Windows 11,
  d'abord « Afficher d'autres options »).

macOS (archive « macos-arm64 » pour les Mac Apple Silicon : M1, M2…,
« macos-x64 » pour les Mac Intel)
  1. Double-cliquez sur l'archive, puis faites glisser Varians-Synchro.app
     dans le dossier Applications.
  2. Premier lancement : Varians-Synchro n'étant pas signé par Apple, macOS
     refuse de l'ouvrir (« Apple ne peut pas vérifier… »). Fermez ce
     message, puis ouvrez Réglages Système → Confidentialité et sécurité :
     en bas, à côté du message sur Varians-Synchro, cliquez sur « Ouvrir
     quand même » et confirmez. Sous macOS 14 ou antérieur, il suffit de
     faire un clic droit (ou Ctrl+clic) sur Varians-Synchro.app → Ouvrir →
     Ouvrir. macOS ne le demande qu'une fois.
  Si macOS dit que Varians-Synchro est « endommagé », tapez dans le
  Terminal :
     xattr -dr com.apple.quarantine /Applications/Varians-Synchro.app

Linux (64 bits x86 ; Ubuntu 22.04, Debian 12, Fedora 36 ou plus récent)
  1. Décompressez l'archive :  unzip Varians-Synchro-{version}-linux-x64.zip
  2. Lancez :                  ./Varians-Synchro-{version}/Varians-Synchro
  Varians-Synchro utilise les bibliothèques graphiques présentes sur tout
  bureau Linux (OpenGL, libxcb, fontconfig). S'il en manque une, par
  exemple sous Debian ou Ubuntu :
     sudo apt install libegl1 libgl1 libxcb1 libxkbcommon0 libfontconfig1


PREMIER ESSAI
-------------
Le dossier demo_local_ALTO, à côté de Varians-Synchro, contient un petit
projet d'exemple (exemple.vsynch : deux témoins d'une page, avec leurs
fichiers ALTO). Copiez ce dossier ailleurs, par exemple dans Documents,
puis ouvrez exemple.vsynch et suivez la section « 2. Premier essai : le
projet d'exemple » du guide.

Varians-Synchro prépare des projets pour Varians, qui se télécharge à part :
  https://github.com/MarjorieBurghart/Varians/releases


METTRE À JOUR
-------------
Téléchargez la nouvelle archive sur la page des versions,
  https://github.com/MarjorieBurghart/Varians-Synchro/releases
puis remplacez l'ancien dossier (ou Varians-Synchro.app) par le nouveau.
Vos projets et vos réglages ne sont pas dans ce dossier : ils sont
conservés.

Pour désinstaller Varians-Synchro, supprimez simplement ce dossier (ou
Varians-Synchro.app).


VÉRIFIER
--------
L'archive : chaque archive a son empreinte SHA-256 (fichier .sha256 sur la
page des versions). Pour la calculer :
  Windows (PowerShell) :  Get-FileHash Varians-Synchro-{version}-windows-x64.zip
  macOS :                 shasum -a 256 Varians-Synchro-{version}-macos-arm64.zip
  Linux :                 sha256sum Varians-Synchro-{version}-linux-x64.zip

L'installation : en cas de problème, Varians-Synchro peut vérifier lui-même
ses traductions, son aide, ses ressources, le projet d'exemple, une
synchronisation avec ses exports vers Varians, et sa fenêtre, et en écrire
le rapport (quelques secondes) :
  Windows (invite de commandes, dans le dossier de Varians-Synchro) :
     start /wait Varians-Synchro.exe --self-test rapport.json
  macOS :
     /Applications/Varians-Synchro.app/Contents/MacOS/Varians-Synchro --self-test ~/rapport.json
  Linux :
     ./Varians-Synchro --self-test rapport.json
Joignez ce rapport à votre signalement :
  https://github.com/MarjorieBurghart/Varians-Synchro/issues
