# 開発者向けドキュメント — V0.8.5.5

構造・形式・テストの詳細は `en.md` と `fr.md` に記載されています。保守では次の規則を守ってください。

- `.vsynch`：バージョン管理された JSON。アトミック保存とバックアップ `.vsynch.bak` を使用し、開く際に既存プロジェクトを書き換えないこと。
- ALTO/PAGE：ポリゴン、行 ID、読み順、対象外範囲を維持すること。
- `reading_stream.py`、`textual_progress.py`：承認済みの V0.7.4 対応付けモデルを維持すること。
- TEI：伝本ごとの `<lb edRef="#ID"/>` を使用し、異読装置に曖昧さがあれば自動関連付けを停止すること。
- `varians_export.py`：`validated/`、`working/`、`base_keys` の意味を明示的な判断なしに変更しないこと。
- `hd_registry.py`：ローカルコピーを書き出す前に Canvas とファイルの対応と必要範囲全体を検証すること。
- `i18n/<lang>.xml`：全言語でキーと置換パラメーターを一致させること。校訂対象の原文は翻訳しないこと。
- テスト：`PYTHONPATH=. pytest -q`。Windows の GUI と Varians へのインポートは別途検証が必要。

詳細は[英語版の技術文書](en.md)と[フランス語版](fr.md)を参照してください。
