# Документация для разработчиков — V0.8.5.5

Полное описание архитектуры и испытаний приведено в `en.md` и `fr.md`. При сопровождении обязательны следующие правила.

- `.vsynch`: версионируемый JSON, атомарное сохранение и резервная копия `.vsynch.bak`; при открытии не перезаписывать существующие проекты.
- ALTO/PAGE: сохранять полигоны, идентификаторы строк, порядок чтения и исключённые области.
- `reading_stream.py`, `textual_progress.py`: не менять утверждённую модель сопоставления V0.7.4.
- TEI: `<lb edRef="#ID"/>` для конкретного свидетеля; неоднозначный критический аппарат должен блокировать автоматическую привязку.
- `varians_export.py`: соблюдать семантику `validated/`, `working/` и `base_keys`; не изменять её без явного решения.
- `hd_registry.py`: перед экспортом локальных копий проверять связи Canvas с файлами и полноту набора.
- `i18n/<lang>.xml`: ключи и параметры форматирования должны совпадать во всех каталогах; тексты источников не переводятся.
- Тесты: `PYTHONPATH=. pytest -q`; ещё необходимы проверка GUI в Windows и импорт в Varians.

См. [полную техническую документацию на английском](en.md) и [французскую версию](fr.md).
