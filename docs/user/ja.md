# ユーザーガイド — Varians-Synchro V0.8.5.5

Varians-Synchro は、ローカル画像や IIIF 画像、ALTO/PAGE の行領域情報を利用して、複数の写本資料の物理的な行を対応付けるツールです。元の資料ファイルは変更しません。

> ALTO / PAGE-XML / IIIF / TEI / HTR / `.vsynch` / `base_keys` は技術的な識別子です。識別子や写本の原文は翻訳しません。

## インストールと起動

Python と PySide6 を用意します。Windows では start_windows.bat または run.py を実行します。Spyder では独立プロセスで起動してください。

## プロジェクトと伝本の登録

新規プロジェクトを作成し、すぐに .vsynch ファイルを保存します。各伝本に識別記号、画像または IIIF Manifest、ALTO/PAGE、必要に応じて TEI XML 版を登録し、基準伝本を指定します。

## 資料の関連付け

第2段階では画像の自然順と XML との対応を確認します。ファイル名の一致を優先し、自然順による組合せは必ず確認する候補として扱います。

## 対象範囲の指定

校訂対象外の行を無視対象にします。本文は複数の段や葉にまたがって構いません。

## TEI と画像行の連結

TEI には対象伝本を示す <lb edRef="#ID"/> が必要です。TEI の行数と対象となる物理行の数を比較し、本文と画像の切り出しを確認します。最初は冒頭の行を表示し、任意の行をクリックして確認できます。異読箇所が曖昧な場合、自動連結は停止します。

## 伝本間の行対応

第3段階で伝本の組を選び、対応する基準点を設定して、本文の進行度に基づく候補を確認します。単クリックは選択の置換、Ctrl+クリックは個別追加・解除、Shift+クリックは範囲選択です。

## 確定と例外

正しい対応を確定し、不確かな候補は修正します。欠落の確定は伝本の組ごとに扱います。手動・確定済みの対応は自動再計算で上書きされません。

## IIIF HD と外部 HTR

必要な Canvas だけを高解像度で保存し、続いてプロジェクトを保存します。ALTO/PAGE が付く必要画像がすべて検証済みの場合に限り、ローカルコピーを Varians へ書き出します。HTR ボタンは任意の外部文字認識処理用です。

## 完了と書き出し

第4段階で読み取り専用の整合性検査を実施します。確定済み validated と作業中 working の JSON、または Varians 用プロジェクトを出力します。

## 保存とトラブル対応

 .vsynch は原子的に保存され、直前の版は .vsynch.bak に残ります。大きな変更前にはバックアップを取り、IIIF が読めないときはネットワークと保存先を確認してください。
